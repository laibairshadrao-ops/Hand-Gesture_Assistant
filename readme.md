# Gesture Assistant

Gesture Assistant is a Python-based computer control system that uses real-time hand gesture recognition through a webcam.

## What It Does

* **Fist:** Captures a screenshot.
* **Victory sign:** Opens the latest screenshot.
* **Thumbs up:** Increases system volume.
* **Thumbs down:** Decreases system volume.
* **Open palm:** Controls media playback.

## Technologies Used

Python, OpenCV, MediaPipe, PyAutoGUI, pyttsx3, and WinSDK.


## Requirements
- Python 3.12
- Webcam
